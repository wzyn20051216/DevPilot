# DevPilot 项目介绍

DevPilot 是面向代码仓库的智能研发协作平台，技术栈包括 Python、FastAPI、Vue 3、Tool Calling、Hybrid Code RAG、MCP、Docker、Redis 与 MySQL。

## 项目能力

- 打通本地需求与 GitHub Issue、计划审批、代码修改、隔离验证、结果审查和 Draft PR 发布，结合 SSE、事件与工具记录支持全过程追踪。
- 实现 AST/窗口分块、BM25、向量与 RRF 融合检索，按仓库与任务特征选择结构导航和行为探针，并使用上下文压缩与工具观测去重控制长任务上下文。
- 实现 API/Worker 分离、SQL/Redis 原子领取、租约心跳、领取令牌、有限重试、背压与取消收尾，接入应用 Key、目录授权和 Docker 资源限制。
- 将运行代码、验证工具与研究材料分层管理，生产镜像排除测试及历史工作区，最终结果通过只读快照发布。

## 实测依据

最后真实缺陷批次覆盖 9 道有效 SWE-bench Verified Issue，每题重复 2 次，独立文件级测试通过 14/18（77.8%），流程完整成功 10/18（55.6%）。

RAG 720 组参数对照中，16 条本项目验证查询的选定配置 Recall@5 为 84.38%、MRR 为 0.6615，返回上下文字符数相对同批默认减少 47.65%。这些指标保留本项目样本范围，不解释为生产费用或跨仓库泛化收益。

本次整理后的后端回归为 242 项通过，包含真实 MySQL/Redis；前端 8 项测试及生产构建通过。最终证据集中于 `research/results/latest`。

## 简历项目描述

构建面向代码仓库的智能研发协作平台，完成需求导入、计划审批、工具执行、隔离测试与 Draft PR 发布；实现 Hybrid Code RAG、动态工具策略和可观测执行链，结合持久化队列、租约校验、背压及访问授权管理任务。建立独立裁判与参数评估流程，在 9 道真实 Issue 的 18 次重复评测中取得 14 次独立测试通过，并通过含 MySQL/Redis 的后端回归验证。
