这是一份围绕真实项目展开的学习文档。正文来自经过源码核对的[飞书技术知识库](https://dcn4btp2pzsc.feishu.cn/wiki/TLjZwYvmRivtOZk0nvkcuXEBnJg)，按照概念、执行、架构、工具、检索、评测和部署重新组织。每一章都能从概念跳到具体实现，并用现有回归测试检查理解。

## 如何使用每一章

1. 先看“学习目标”，确定这一章要解决的问题。
2. 阅读正文与配图，遇到具体行为时打开“源码导航”。
3. 完成“动手与自检”，再展开参考答案核对。
4. 用页尾的“上一章／下一章”连续阅读，或返回目录切换路线。

所有终端命令默认在仓库根目录执行。优先使用现有的离线回归；真实模型实验会调用配置的模型，需另外准备镜像、数据、预算与验收目标。
